# Getting Started

Th project **ClaudeSportBets** tries to recreate the project **footballBets** (written conventionally by hands) 
by means of Claude AI.

Basically, the 21 entities should provide the base for the Spring Boot Java  backend. Fields and Relations
should be described by Claude readable text. When the entities have been created, JPA repositores, Services and
REST Controllers should be created by instructions provided for Claude.

Business Rules and Best Practice instructions should accompany later.
